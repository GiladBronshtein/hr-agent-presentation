## מה זה?

הרצאה של 30 דקות לאנשי למידה ופיתוח (L&D): צוותי הדרכה, עיצוב למידה וטכנולוגיות למידה, ומי שאחראים על קליטה ושימור ידע. ההרצאה עונה על ארבע שאלות פשוטות:

1. מה זה אייג׳נט, ומה הוא נותן ל-L&D?
2. איך זה נראה בפועל?
3. איך לבנות את זה באחריות?
4. איך להתחיל בארגון שלנו?

כל הדוגמאות לקוחות מהעבודה היומיומית של L&D: אבחון צרכים, פיתוח תוכן, מסלולי למידה, תרגול, מדידת אימפקט, קליטה ושימור ידע.

המצגת בנויה להצגה על מסך גדול מול קהל, ועובדת גם בטלפון: כל סלייד שומר על הפריסה שלו ומוקטן למסך.

## מבנה ההרצאה

המסלול הראשי (סליידים 0 עד 24) הוא ההרצאה עצמה, 30 דקות. הנספח (סליידים 25 עד 50) הוא חומר עיון, זמין ממפת הפרקים.

| פרק | סליידים | מה רואים |
|-----|---------|----------|
| להבין | 0-7 | שבוע אחד ב-L&D, אוטומציה לעומת אייג׳נט, ממה בנוי אייג׳נט, איך התפקיד שלנו משתנה |
| לראות | 8-18 | מחזור הלמידה, ארבעה אייג׳נטים (אבחון צרכים, פיתוח תוכן, מסלול אישי, מדידת אימפקט) ודמו חי |
| לבנות | 19-20 | כלים שכבר יש בארגון, אמון וגבולות |
| להטמיע | 21-24 | בחירת פיילוט, מפת דרכים ל-90 יום, צעד ראשון השבוע, סיום |
| נספח | 25-50 | מפת תשעת האייג׳נטים, חמישה אייג׳נטים נוספים, שלבי הדמו המורחב, הגדרות, משילות, הרשאות, מדידת ערך, קנבס אייג׳נט, הוראות מערכת לדוגמה, תרשים n8n ומפת כלים |

ההערות לכל סלייד נמצאות ב-`client/src/data/speakerNotes.ts`, והסדר והפרקים ב-`client/src/data/scenes.ts`.

בנספח יש ארבעה שלבים נוספים של הדמו המורחב: איסוף מידע, שימוש בכלים, ביצוע, ומשוב ושיפור.

## שפת התנועה: קו מסלול הלמידה

כל התנועה במצגת נשענת על רעיון אחד: קו אחד רציף שמצייר, מחבר ומגלה.

- **טריילר הפתיחה (כ-73 שניות, בשקף הכותרת):** אותו קו מספר את כל ההרצאה. נקודה פועמת הופכת לקו מהסס, הקו רץ הלוך ושוב בין הכלים של תוכנית למידה עד שנוצר סבך, מסלול אוטומציה נוקשה נתקע מול שאלה בזמן שהקו של האייג׳נט עוקף אותה ומגיע למטרה, מחזור הלמידה מצויר כלולאה עם תשעה אייג׳נטים, בקשה ב-Slack הופכת לתוכנית שאדם מאשר, שכבות אמון מצוירות ומגודרות, ומפת הדרכים ל-90 יום נמתחת על המסך. בסוף הקו כותב את הכותרת ונעצר בדיוק בקו הענבר שמתחתיה, ושקף הכותרת נחשף מתחתיו. הפסקול (פסנתר רך, כלי קשת, צליל העט ודופק הלב מהפתיחה) מסונכרן לכל משיכה על המסך.
- **מעברים בין סליידים:** קו מסלול נכנס מצד הקריאה (ימין), עובר בנקודה שבה הסלייד הבא נפתח, וממשיך הלאה. כל מעבר מקבל עקומה משלו, קבועה וניתנת לשחזור.
- **כרטיסי פרק:** בפתיחת כל פרק, הקו כותב את מספר הפרק במשיכה אחת, ושם הפרק מופיע לצדו.
- **מנגינה שנבנית:** פסנתר רך (felt piano) מנגן תו אחד בכל מעבר סלייד, והמנגינה נבנית תו אחרי תו לאורך ההרצאה. בפתיחת פרק נשמע אקורד.
- **רגע האישור בדמו:** כשלוחצים "אישור וביצוע", קו ענבר אחד מצייר סימן וי.
- **פלטה מאופקת:** כחול כהה, לבן נייר, ענבר אחד להדגשה, ואפור כחלחל למשני. בלי זוהר, בלי טקסט בגרדיאנט ובלי חלקיקים.
- **תנועה מופחתת:** כל האנימציות מכבדות `prefers-reduced-motion` ואת מתג התנועה המופחתת במצגת.

הגיאומטריה והפלטה המשותפות נמצאות ב-`client/src/components/motion/path.ts`.

## בקרות להצגה

| מקש | פעולה |
|-----|-------|
| `←` / `→` | ניווט בין סליידים |
| `Space` | סלייד הבא |
| `Esc` | מפת פרקים |
| `N` | תצוגת מרצה בחלון נפרד (סלייד נוכחי, הבא, הערות, טיימר) |
| `B` | מסך שחור |
| `P` | הערות מרצה |
| `H` | עזרת מקלדת |
| `F` | מסך מלא |
| `M` | השתקה והפעלה של הסאונד |
| `Enter` | דילוג על טריילר הפתיחה |
| `I` | הפעלה חוזרת של טריילר הפתיחה |

עוד דברים שכדאי לדעת:

- **קישורים עמוקים:** לכל סלייד כתובת משלו בפורמט `#/scene/<id>`, ורענון מחזיר לאותו סלייד.
- **תצוגת מרצה:** מסונכרנת בשני הכיוונים דרך BroadcastChannel, ועובדת גם בלי אינטרנט.
- **בלי תלות ברשת:** הגופנים מוטמעים בפרויקט, כך שאין צורך באינטרנט באולם.
- **טלפון:** ניווט בהחלקה, וכשהמכשיר לאורך מוצגת הצעה לסובב אותו.

## הפעלה מקומית

הפרויקט עובד עם pnpm בלבד, דרך `npx pnpm@10.4.1`:

```bash
git clone https://github.com/GiladBronshtein/hr-agent-presentation.git
cd hr-agent-presentation

npx pnpm@10.4.1 install     # התקנת תלויות
npx pnpm@10.4.1 dev         # שרת פיתוח על http://localhost:3000
npx pnpm@10.4.1 check       # בדיקת טיפוסים (tsc)
npx pnpm@10.4.1 build       # בנייה לפרודקשן
```

### פרסום ל-GitHub Pages

האתר מוגש מתיקיית `docs/` בענף main. הבנייה לפרסום צריכה את נתיב הבסיס של הרפוזיטורי, ואז מסנכרנים את התוצר לתיקייה:

```bash
VITE_BASE_PATH=/hr-agent-presentation/ npx pnpm@10.4.1 build
rsync -a --delete --exclude .nojekyll --exclude .gitkeep dist/public/ docs/
git add docs && git commit -m "deploy" && git push
```

### עדכון פסקול הטריילר

הפסקול נשמר כקובץ `client/public/audio/trailer-score.flac`. אחרי שינוי ב-`components/presentation/trailer/score.ts` או בכלי הנגינה ב-`lib/sound.ts` צריך לרנדר אותו מחדש, לפי ההוראות שבראש `score.ts`.
