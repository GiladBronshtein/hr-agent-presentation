## מה זה?

הרצאה של 30 דקות לאנשי למידה ופיתוח (L&D): צוותי הדרכה, עיצוב למידה וטכנולוגיות למידה, ומי שאחראים על קליטה ושימור ידע. ההרצאה עונה על ארבע שאלות פשוטות:

1. מה זה אייג׳נט, ומה הוא נותן ל-L&D?
2. איך זה נראה בפועל?
3. איך לבנות את זה באחריות?
4. איך להתחיל בארגון שלנו?

כל הדוגמאות לקוחות מהעבודה היומיומית של L&D: אבחון צרכים, פיתוח תוכן, מסלולי למידה, תרגול, מדידת אימפקט, קליטה ושימור ידע.

המצגת בנויה להצגה על מסך גדול מול קהל, ועובדת גם בטלפון: כל סלייד שומר על הפריסה שלו ומוקטן למסך.

## מבנה ההרצאה

המסלול הראשי (סליידים 0 עד 27) הוא ההרצאה עצמה, כ-29 דקות. הנספח (סליידים 28 עד 47) הוא חומר עיון, זמין ממפת הפרקים, ומסתיים בשקף המקורות.

| פרק | סליידים | מה רואים |
|-----|---------|----------|
| להבין | 0-8 | שבוע אחד ב-L&D, למה דווקא עכשיו, אוטומציה לעומת אייג׳נט, ממה בנוי אייג׳נט, איך התפקיד שלנו משתנה |
| לראות | 9-20 | מחזור הלמידה, אייג׳נט לכל שלב (אבחון צרכים, מסלול למידה אישי, פיתוח תוכן, תרגול בסימולציה, מדידת אימפקט) ודמו חי |
| לבנות | 21-23 | כלים שכבר יש בארגון, אמון וגבולות, והחששות שעולים בכל ארגון |
| להטמיע | 24-27 | בחירת פיילוט, מפת דרכים ל-90 יום, צעד ראשון השבוע, סיום |
| נספח | 28-47 | מפת תשעת האייג׳נטים, ארבעה אייג׳נטים נוספים, שלבי הדמו המורחב, עץ החלטה, עקרונות למידה, משילות, הרשאות, מדידת ערך, קנבס אייג׳נט, הוראות מערכת לדוגמה, תרשים n8n, בדיקה לפני השקה, מפת כלים ומקורות |

ההערות לכל סלייד נמצאות ב-`client/src/data/speakerNotes.ts`, והסדר והפרקים ב-`client/src/data/scenes.ts`.

## שפה חזותית ותנועה: Spectrum ועט של אור

- **פלטת Spectrum:** חצות כחולה עמוקה, טקסט בלבן חם, וצבע אור לכל פרק: להבין סגול, לראות טורקיז, לבנות אלמוג, להטמיע ענבר, נספח כחול. לכל שקף יש תאורת במה חיה בצבע הפרק שלו. הפלטה מוגדרת ב-`client/src/lib/palette.ts`.
- **טריילר הפתיחה (כ-73 שניות, בשקף הכותרת):** יקום של 16,000 חלקיקים בכרטיס המסך (WebGL), עם קפיצות היפר-חלל בין הפרקים, ועליו עט של אור שמספר את הסיפור: דופק לב שהופך לרצועת אק״ג, קווים צבעוניים שרצים בין הכלים של תוכנית למידה עד שנוצר סבך, מספרי הפרקים נכתבים באור, לולאת אור שמחברת את רכיבי האייג׳נט, תשעת האייג׳נטים מחוברים בשרשרת, קרני אור ברגע האישור בדמו, מגן אמון ומפת דרכים מצוירים באור. בסוף החלקיקים יוצרים את הכותרת, ושביט של אור נוחת בדיוק על הקו שמתחתיה. הסאונד פועל כברירת מחדל, ויש כפתור השתקה בטריילר עצמו (וגם המקש M).
- **פסקול:** פסקול קולנועי חם (A minor, 90 BPM): דופק, ארפג׳יו, פדים וברָאמים, כלי קשת חמים וסאב-בס מתמשך מתחת לכל תיבה, מנגינת פסנתר רך מהפרק השני, וצליל לכל משיכת עט. מרונדר מראש לקובץ FLAC (`client/public/audio/trailer-score.flac`).
- **מעברים בין סליידים:** קו אור בצבע הפרק נכנס מצד הקריאה, מתפוצץ בנקודה שבה הסלייד הבא נפתח (אור, טבעת זוהרת וניצוצות), והשקף הבא נפתח מתוכה.
- **כרטיסי פרק:** דף של אור בצבע הפרק, מספר הפרק נכתב בקו אור אחד, קרניים פורצות ממנו, ושם הפרק זוהר.
- **מנגינה שנבנית:** פסנתר רך מנגן תו אחד בכל מעבר, והמנגינה נבנית לאורך ההרצאה. בפתיחת פרק נשמע אקורד.
- **סיום ההרצאה:** בשקף הסיום יקום החלקיקים חוזר, מתפוצץ לגלקסיה צבעונית ונאסף לפניו של המרצה: כל חלקיק מקבל את המיקום והצבע של פיקסל מהתמונה, עם דופק הלב מהפתיחה ואקורד סיום, ואז החלקיקים הופכים לתמונה האמיתית והשקף נחשף סביבה.
- **תנועה מופחתת:** כל האנימציות מכבדות `prefers-reduced-motion` ואת מתג התנועה המופחתת במצגת.

## בקרות להצגה

| מקש | פעולה |
|-----|-------|
| `←` / `→` | ניווט בין סליידים |
| `Space` | סלייד הבא |
| `Esc` | מפת פרקים |
| `N` | תצוגת מרצה בחלון נפרד (סלייד נוכחי, הבא, הערות, טיימר) |
| `B` | מסך שחור |
| `P` | הערות מרצה |
| `H` | עזרת מקלדת |
| `F` | מסך מלא |
| `M` | השתקה והפעלה של הסאונד |
| `Enter` | דילוג על טריילר הפתיחה |
| `I` | הפעלה חוזרת של טריילר הפתיחה |

עוד דברים שכדאי לדעת:

- **קישורים עמוקים:** לכל סלייד כתובת משלו בפורמט `#/scene/<id>`, ורענון מחזיר לאותו סלייד.
- **תצוגת מרצה:** מסונכרנת בשני הכיוונים דרך BroadcastChannel, ועובדת גם בלי אינטרנט.
- **בלי תלות ברשת:** הגופנים מוטמעים בפרויקט, כך שאין צורך באינטרנט באולם.
- **טלפון:** ניווט בהחלקה, וכשהמכשיר לאורך מוצגת הצעה לסובב אותו.

## הפעלה מקומית

הפרויקט עובד עם pnpm בלבד, דרך `npx pnpm@10.4.1`:

```bash
git clone https://github.com/GiladBronshtein/hr-agent-presentation.git
cd hr-agent-presentation

npx pnpm@10.4.1 install     # התקנת תלויות
npx pnpm@10.4.1 dev         # שרת פיתוח על http://localhost:3000
npx pnpm@10.4.1 check       # בדיקת טיפוסים (tsc)
npx pnpm@10.4.1 build       # בנייה לפרודקשן
```

### פרסום ל-GitHub Pages

האתר מוגש מתיקיית `docs/` בענף main. הבנייה לפרסום צריכה את נתיב הבסיס של הרפוזיטורי, ואז מסנכרנים את התוצר לתיקייה:

```bash
VITE_BASE_PATH=/hr-agent-presentation/ npx pnpm@10.4.1 build
rsync -a --delete --exclude .nojekyll --exclude .gitkeep dist/public/ docs/
git add docs && git commit -m "deploy" && git push
```

### עדכון פסקול הטריילר

הפסקול נשמר כקובץ `client/public/audio/trailer-score.flac`. אחרי שינוי ב-`components/presentation/trailer/score.ts` או בכלי הנגינה ב-`lib/sound.ts` צריך לרנדר אותו מחדש, לפי ההוראות שבראש `score.ts`.
